=== WP NTK ===
Requires at least: 6.2
Tested up to: 7.1
Requires PHP: 7.4
Stable tag: 10.1.0

Личный кабинет наставника проекта с формой регистрации.

== Description ==

Плагин добавляет на сайт личный кабинет наставника проекта.

* Регистрация. Сведения о наставнике и организации: ФИО наставника проекта, образовательная организация (полное название, адрес и номер телефона), должность, номера телефонов, муниципальное образование, электронная почта организации. Отдельным блоком — данные для входа: email наставника и пароль.
* Вход по электронной почте и паролю, восстановление пароля на странице кабинета по ссылке из письма.
* Кабинет: наставник видит и исправляет свои данные, меняет пароль, выходит.

Обязательность полей анкеты настраивается администратором; email аккаунта, пароль и согласие обязательны. После регистрации наставник сразу попадает в кабинет: подтверждение по почте и одобрение администратором не требуются. При регистрации требуется согласие на обработку персональных данных. Текст согласия и необязательный URL документа настраиваются в разделе «WP NTK» консоли; при регистрации сохраняются дата, текст и адрес документа. Существующим пользователям согласие повторно не показывается.

Наставники получают роль «Наставник проекта». Консоль WordPress и верхняя панель им недоступны: вместо консоли открывается личный кабинет.

Администратор видит и может исправить данные наставника в его профиле (раздел «Пользователи»). ФИО и организация показаны в списке пользователей.

== Installation ==

1. Установите плагин: «Плагины → Добавить плагин → Загрузить плагин» и выберите zip-архив. Либо скопируйте папку `wp-ntk` в `/wp-content/plugins/`.
2. Активируйте плагин. При активации создаётся страница «Личный кабинет» с шорткодом `[wp_ntk_account]`.
3. Добавьте страницу «Личный кабинет» в меню сайта.

В редакторе страницы «Личный кабинет» можно добавить блоки до и после шорткода. Эти блоки отображаются также на экранах входа и кабинета. В меню «WP NTK → Поля регистрации» настраиваются подписи, порядок и обязательность полей анкеты; там же добавляются строки, текстовые области, выпадающие списки и флажки. Поля входа и согласия на обработку данных остаются обязательными. Убранные дополнительные поля перестают отображаться, но сохранённые данные не удаляются.

Шорткод `[wp_ntk_account]` можно вставить и на любую другую страницу. Ссылка сразу на форму регистрации: адрес страницы кабинета с параметром `?wp_ntk_view=register`.

== Регистрация проектов ==

В меню «WP NTK → Проекты» настройте четыре названия номинаций и общий период приёма. Дата и время задаются в часовом поясе сайта WordPress («Настройки → Общие»). До настройки периода приём закрыт. Открытие — в указанную минуту начала, закрытие — в указанную минуту окончания. Переименование номинации меняет её название и у ранее поданных проектов. После окончания приёма автоматически закрывается регистрация новых пользователей через форму WP NTK; вход существующих пользователей сохраняется. Стандартная регистрация WordPress и формы других плагинов не изменяются. При продлении срока регистрация снова доступна, если не закрыта вручную. При отсутствии настроенного периода автоматическое закрытие не действует.

Во вкладке «Проекты» личного кабинета наставник или пользователь с ролью «Подписчик» может подать любое число проектов: название, описание и номинация. Администратору также доступен этот раздел; созданные им проекты принадлежат его учётной записи. Когда приём закрыт, кнопка регистрации видна, но неактивна. Свои проекты можно просматривать в любое время, а редактировать — только во время приёма. Администратор видит все проекты в разделе «WP NTK → Проекты», может переместить их в корзину и восстановить до её автоматической очистки. Проекты не входят в CSV наставников; их экспорт настраивается отдельно.

== Внешний вид ==

В разделе «WP NTK → Внешний вид» настраиваются цвета кабинета и панели плагина, шрифт, размеры, отступы и дополнительный CSS. Пока настройки не сохранены, прежний дизайн не меняется. Кнопка сброса возвращает стандартное оформление. Дополнительный CSS выводится на страницах с кабинетом и на экранах панели WP NTK; используйте селекторы `.wp-ntk` для кабинета. Тема сайта может влиять на конечный вид.

== Email-уведомление о регистрации ==

В разделе «WP NTK → Email-уведомления» можно включить письмо наставнику после регистрации, изменить тему и текст. Письмо отправляется на email учётной записи, не на адрес организации. Подстановки: `{name}`, `{email}`, `{site}`, `{account_url}`. По умолчанию уведомление отключено. Для доставки требуется работающая почта WordPress.

== Файлы проектов ==

Новые вложения хранятся в настроенной сетевой папке SMB в wp-ntk-private/site-ID. Это основное хранилище, а не выгрузка; экспорт его не копирует. Настройте подключение в разделе «Сетевая папка» и предоставьте учётной записи право создавать и удалять файлы. При недоступности SMB загрузка и скачивание новых файлов невозможны. Ограничьте доступ к сетевой папке средствами SMB: пользователи сети с доступом к папке могут читать файлы независимо от прав WordPress. Не публикуйте папку по HTTP. Серверные временные каталоги PHP также должны быть недоступны по HTTP; временные файлы необходимы при загрузке и скачивании.

Если прежнее хранилище файла недоступно, автор может выбрать новый файл и отдельно подтвердить замену. Прежний файл плагин не удаляет; сведения о нём сохраняются в базе и отображаются администратору в списке проектов. Эти сведения не являются резервной копией файла, а старый путь SMB в них может отсутствовать. Экспорт может изменить старую сетевую выгрузку — при необходимости предварительно скопируйте её. При окончательном удалении проекта сведения о прежних файлах тоже удаляются. Новая загрузка по-прежнему требует доступного SMB-хранилища.

Вложения, загруженные до версии 2.0.0 в локальную закрытую папку, остаются там и не мигрируются автоматически. Для их чтения сохраните настройку WP_NTK_PRIVATE_DIR и прежние файлы. Смена SMB-пути через настройки запрещена, пока в сетевом хранилище есть вложения проектов: автоматический перенос не предусмотрен. Резервируйте базу, старую закрытую и сетевую папки. При ошибке удаления в хранилище могут остаться осиротевшие копии: проверяйте журнал PHP.

В «WP NTK → Файлы проектов» можно настроить разделы, форматы PDF, DOCX, XLSX, PPTX, JPG, PNG, размер и обязательность. В каждый раздел загружается один файл. Во время приёма необязательный файл можно сразу удалить отдельной кнопкой; несохранённые изменения формы при этом не сохраняются; копия из выгрузки удаляется при следующей синхронизации. Обязательный файл можно заменить, но нельзя удалить отдельно. Настройки разделов можно редактировать и удалять. При удалении раздела ранее загруженные файлы остаются доступны в проектах и в выгрузке, но исчезают из формы редактирования. Ограничения PHP и сервера могут быть ниже настроенных; суммарный размер ограничен post_max_size. Скачивание через WordPress доступно автору и администраторам. Файлы в корзине сохраняются до окончательного удаления. Проверка формата не заменяет антивирусную проверку.

== Дополнительные поля проектов ==

В «WP NTK → Поля проектов» администратор добавляет поля с названием, типом, порядком и обязательностью. Для списка варианты указываются по одному на строку. Тип созданного поля не меняется; при изменении вариантов прежние ответы сохраняются. Удаление поля после подтверждения безвозвратно удаляет его ответы у всех проектов, включая корзину. Сделайте резервную копию перед удалением. При изменении настроек в момент заполнения пользователю потребуется обновить форму. Ответы отображаются в кабинете, панели администратора и в XLSX/PDF проекта. Файловые разделы настраиваются отдельно.

== Экспорт проектов в SMB ==

На странице «Файлы проектов» в блоке «Экспорт проектов в SMB» администратор запускает ручную синхронизацию или включает автоматическую после изменений и по расписанию. Используются реквизиты из раздела «Сетевая папка». Папки создаются непосредственно в настроенной сетевой папке по названиям номинаций: Название номинации/Название проекта. Недопустимые в именах символы заменяются, слишком длинные названия сокращаются, при совпадениях добавляется суффикс. Исходные имена новых вложений по возможности сохраняются; в старых вложениях используется имя, сохранённое прежней версией плагина. После успешной записи файлов старые файлы плагина из прежней структуры удаляются; пустые папки плагин пытается удалить, посторонние файлы остаются. Для каждого сайта используйте выделенную папку и не занимайте вручную зарезервированные имена файлов: плагин ведёт реестр своих выгрузок в базе WordPress. Создаются файлы «Название проекта.xlsx» и «Название проекта.pdf» с данными проекта и списком вложений, без ID проекта и данных наставника, и наставник.xlsx со всеми настроенными полями анкеты, email аккаунта и ID наставника. Пароли не выгружаются. Файл project.json больше не создаётся; ранее экспортированные и зарегистрированные плагином файлы project.json удаляются при успешной синхронизации. При удалении наставником вложения плагин немедленно пытается обновить выгрузку независимо от настройки автоматического экспорта; при ошибке назначается повторная попытка через WP-Cron. Для XLSX необходим ZipArchive, для PDF — iconv и zlib; временный каталог PHP должен быть недоступен по HTTP и не находиться внутри публичного каталога сайта. При успешной синхронизации плагин удаляет устаревшие ранее экспортированные им файлы, но не чужие файлы; пустые каталоги могут остаться. При смене сетевого пути старые копии остаются на прежнем ресурсе и требуют ручного удаления. Папка SMB должна быть закрыта от посторонних: права WordPress на выгруженные копии не распространяются. Выгрузка неатомарна; при ошибке данные могут быть неполными. Резервные копии автоматически не очищаются. WP-Cron зависит от посещений или системного cron. Следите за статусом выгрузки.

== Сетевая папка SMB ==

В «WP NTK → Сетевая папка» укажите UNC-путь `//сервер/ресурс/каталог`, логин, пароль и при необходимости домен, сохраните настройки и проверьте подключение. Общий файл `mentors.csv` в сетевую папку больше не выгружается. Ранее созданный файл автоматически не удаляется; при необходимости удалите его вручную. Анкета наставника по-прежнему экспортируется в XLSX в папке проекта.

На сервере WordPress требуются PHP OpenSSL, разрешённый `proc_open` и `smbclient` с поддержкой `--client-protection=encrypt`; сервер SMB должен поддерживать шифрование SMB3. Пароль хранится в базе зашифрованным с использованием ключей WordPress; после их смены потребуется ввести его заново. Временные файлы данных и реквизитов создаются с правами 0600 и удаляются после операции.


== Frequently Asked Questions ==

= Отправляет ли плагин письма? =

Плагин отправляет письмо со ссылкой на восстановление пароля и, если включено, письмо о регистрации на email аккаунта. Уведомление о смене пароля отправляет WordPress. Для доставки необходимо настроить почту на сайте.

= Как изменить цвет кнопок? =

Добавьте в дополнительные стили темы, подставив свои цвета:

`.wp-ntk { --wp-ntk-accent: #0a7d55; --wp-ntk-accent-hover: #086445; }`

= Что останется после отключения или удаления плагина? =

Учётные записи наставников, их данные и страница «Личный кабинет» сохраняются. При повторной активации вторая страница не создаётся.
