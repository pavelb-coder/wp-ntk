=== WP NTK ===
Requires at least: 6.2
Tested up to: 7.1
Requires PHP: 7.4
Stable tag: 1.3.0

Личный кабинет наставника проекта с формой регистрации.

== Description ==

Плагин добавляет на сайт личный кабинет наставника проекта.

* Регистрация. Сведения о наставнике и организации: ФИО наставника проекта, образовательная организация (полное название, адрес и номер телефона), должность, номера телефонов, муниципальное образование, электронная почта организации. Отдельным блоком — данные для входа: email наставника и пароль.
* Вход по электронной почте и паролю, ссылка на восстановление пароля.
* Кабинет: наставник видит и исправляет свои данные, меняет пароль, выходит.

Все поля формы обязательные. После регистрации наставник сразу попадает в кабинет: подтверждение по почте и одобрение администратором не требуются.

Наставники получают роль «Наставник проекта». Консоль WordPress и верхняя панель им недоступны: вместо консоли открывается личный кабинет.

Администратор видит и может исправить данные наставника в его профиле (раздел «Пользователи»). ФИО и организация показаны в списке пользователей.

== Installation ==

1. Установите плагин: «Плагины → Добавить плагин → Загрузить плагин» и выберите zip-архив. Либо скопируйте папку `wp-ntk` в `/wp-content/plugins/`.
2. Активируйте плагин. При активации создаётся страница «Личный кабинет» с шорткодом `[wp_ntk_account]`.
3. Добавьте страницу «Личный кабинет» в меню сайта.

Шорткод `[wp_ntk_account]` можно вставить и на любую другую страницу. Ссылка сразу на форму регистрации: адрес страницы кабинета с параметром `?wp_ntk_view=register`.

== Frequently Asked Questions ==

= Отправляет ли плагин письма? =

Нет. Письмо для восстановления пароля и уведомление о смене пароля отправляет сам WordPress.

= Как изменить цвет кнопок? =

Добавьте в дополнительные стили темы, подставив свои цвета:

`.wp-ntk { --wp-ntk-accent: #0a7d55; --wp-ntk-accent-hover: #086445; }`

= Что останется после отключения или удаления плагина? =

Учётные записи наставников, их данные и страница «Личный кабинет» сохраняются. При повторной активации вторая страница не создаётся.
